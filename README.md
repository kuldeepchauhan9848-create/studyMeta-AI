# StudyMeta-AI 📚🤖

An AI-powered Android application designed to help students learn, manage notes, and access study-related resources in an easy way.

## 🚀 Features

- 📚 Student-friendly study interface
- 🤖 AI Study Assistant
- 📝 Notes section
- 💻 Java learning section
- 📊 Data Types and Variables learning
- 🎯 Simple and easy-to-use UI

## 🛠️ Technologies Used

- Java
- XML
- Android Studio
- Gradle
- Android SDK

## 📱 Application

StudyMeta-AI is designed as a student learning companion with different sections for learning programming concepts and managing study material.

## 📂 Project Structure

- `app/` - Android application source code
- `app/src/main/java/` - Java source files
- `app/src/main/res/layout/` - XML layouts
- `app/src/main/res/drawable/` - Images and resources
- `gradle/` - Gradle configuration

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Wait for Gradle Sync to complete.
4. Connect an Android device or start an emulator.
5. Click **Run ▶️**.
